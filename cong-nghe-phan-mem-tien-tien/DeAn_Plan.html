File ngữ cảnh có giúp agent sửa lỗi?

Cùng một issue, chạy ba lần: không ngữ cảnh, AGENTS.md do người viết, và bản do LLM sinh. Đo xem file đó giúp pass test hay chỉ tốn token.

  • 50task SWE-bench
  • 5repository
  • 3biến thể
  • 7ngày sprint
Xem thiết kế thí nghiệm

01 — Vấn đề

Một file markdown, hai khả năng

Lập trình viên đang đặt CLAUDE.md, AGENTS.md, .cursorrules vào repo để hướng dẫn coding agent. Câu hỏi: file đó giúp agent sửa lỗi tốt hơn, hay chỉ chiếm context window?

Sửa đúng hơn

Agent biết sẵn lệnh test và kiến trúc, nên tìm mò ít hơn và pass nhiều hơn.

Chỉ tốn chỗ

File chiếm context. Tỉ lệ pass không đổi, còn token và tiền thì tăng.

Bài baseline Agent READMEs mô tả các file này trông thế nào. Đề án đi bước tiếp: đo chúng thay đổi kết quả của agent ra sao.

05 — Pipeline

Năm bước, mỗi bước một file

Bên trái là việc cần làm, bên phải là thứ bước đó sinh ra cho bước sau.

  1. Chuẩn bị dữ liệu dataset_loader.py

    • Cài swebench, docker, datasets, pandas.
    • Lấy 50 task, mười task mỗi repo.
    Radata/swe_bench_sample.json

  2. Tiêm ngữ cảnh context_injector.py

    • get_context_file(repo, variant): V0 trả None, V1 đọc file người viết, V2 gọi LLM sinh rồi lưu.
    • inject_into_container(id, content) ghi AGENTS.md vào gốc repo.
    Radata/human_contexts/{repo}/AGENTS.md
    data/synthetic_contexts/{repo}/AGENTS.md

  3. Chạy agent runner.py

    • Mỗi cặp (task, biến thể): bật container, tiêm file, đưa mô tả issue cho agent.
    • Ghi token, thời gian, số lần gọi công cụ, và git patch cuối.
    Raresults/raw_trajectories/{task}_{variant}.json

  4. Chấm điểm evaluator.py

    • Áp patch trong harness SWE-bench, chạy test suite của task.
    • Ghi resolved, lỗi test, số bước, số lần tìm kiếm, tổng chi phí token.
    RaMột dòng mỗi lượt trong results/metrics_summary.csv

  5. Phân tích plotter.py

    • Vẽ bằng matplotlib / seaborn.
    • Xuất bảng LaTeX để chèn thẳng vào bài.
    RaBa biểu đồ và bảng tóm tắt (xem mục 06)
